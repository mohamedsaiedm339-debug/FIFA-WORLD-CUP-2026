# FIFA-WORLD-CUP-2026
Fifa World Cup 2026 Dashboard 
⚽ Turning World Cup Data into a Story | Power BI Project

What if football data could tell the story of the tournament beyond the final score?

I recently built an interactive Power BI Dashboard for FIFA World Cup 2026 data, transforming raw football data into an analytical story that explores teams, matches, goals, players, and stadiums.

The goal wasn't just to create charts — it was to turn the data into something that answers real questions.

🏆 What does the dashboard explore?

🏠 Home Page
A high-level overview of the tournament with key KPIs and interactive navigation across the dashboard.

🌍 Teams Analysis
I analyzed team performance through:

Matches played
Wins, draws & losses
Goals scored & conceded
Goal difference
Points
Interactive team selection using national flags 🇪🇸🇦🇷🇧🇷🇪🇬

⚽ Goals Analysis
The goals page dives deeper into the scoring story:

Total Goals
Normal Goals
Own Goals
Top Scorers
Goals by Team
Goals by Minute
Average Goals per Match

The dataset contains 308 goals, allowing the dashboard to move from tournament-level insights to individual player performance.

🏟️ Stadium Analysis
I also explored the venues behind the tournament:

Number of stadiums
Stadium capacity
Matches hosted by each stadium
Matches by city
Average & largest stadium capacity
📊 Key Numbers

308 ⚽ Total Goals
294 ⚽ Normal Goals
14 🔴 Own Goals
104 🏟️ Matches
48 🌍 Teams
16 🏟️ Stadiums

💡 The main idea behind the project

For me, the most important part of a dashboard isn't how many visuals it contains.

It's whether the user can answer questions quickly.

Instead of presenting raw tables, I focused on:

Data → Analysis → Visualization → Insight

I also used interactive filtering to allow users to select a team and explore its performance across the dashboard.
